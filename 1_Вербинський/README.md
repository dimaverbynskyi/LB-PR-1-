# Лабораторна робота 1: Системи координат

## Про проєкт
У цій роботі реалізовано набір імутабельних (незмінних) структур даних для роботи з точками у двовимірному та тривимірному просторах. Програма підтримує роботу з декартовою, полярною та сферичною системами координат, дозволяє виконувати точну конвертацію між ними, а також містить дослідження швидкодії різних алгоритмів пошуку відстаней.

## Реалізований функціонал

### 1. Моделі координат
Створено наступні імутабельні класи:
*   `CartesianPoint2D(x, y)` — класична площина (2D).
*   `PolarPoint(radius, angle)` — полярні координати (2D).
*   `CartesianPoint3D(x, y, z)` — декартовий простір (3D).
*   `SphericalPoint(radius, azimuth, polarAngle)` — сферичні координати (3D). 

### 2. Конвертація даних
Для переходу між різними системами додано відповідні методи:
*   Для 2D: `CartesianPoint2D.from_polar()` та `PolarPoint.from_cartesian()`.
*   Для 3D: `CartesianPoint3D.from_spherical()` та `SphericalPoint.from_cartesian()`.

### 3. Розрахунок відстаней
Реалізовано алгоритми пошуку відстаней:
*   Між точками на 2D-площині (декартові та полярні).
*   Між точками у 3D-просторі (декартові).
*   У сферичній системі: розрахунок по прямій (хорді) та по поверхні (дузі).

## Тестування точності конвертації

Щоб переконатися у відсутності втрат при перетвореннях туди-й-назад, було проведено тестування. Похибка у всіх випадках склала нуль.

**Лог для 2D:**
```text
Original Polar: r=5.000000, angle=0.785398
To Cartesian: x=3.535534, y=3.535534
Back to Polar: r=5.000000, angle=0.785398
Error: r=0.0000000000, angle=0.0000000000
```

**Лог для 3D:**
```text
Original Spherical: r=5.000000, azimuth=0.785398, polar=1.047198
To Cartesian: x=3.061862, y=3.061862, z=2.500000
Back to Spherical: r=5.000000, azimuth=0.785398, polar=1.047198
Error: r=0.0000000000, azimuth=0.0000000000, polar=0.0000000000
```

## Аналіз швидкодії

**Двовимірний простір:**
Використання декартової системи виявилося у 2.5 раза швидшим. Це логічно, оскільки полярна система вимагає виклику ресурсомістких тригонометричних функцій.

**Тривимірний простір:**
Декартові координати знову показують найкращий результат. Сферичні розрахунки повільніші у 3–3.5 раза. Цікаво, що обчислення дугової відстані працює трохи швидше за розрахунок хорди — це пов'язано з меншою загальною кількістю математичних операцій у формулі.
