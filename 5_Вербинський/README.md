# Лабораторна робота: Потокова фільтрація координатних даних (Real-time)

## 1. Реалізація методів фільтрації

У рамках роботи імплементовано три типи цифрових фільтрів для обробки потокових даних (імітація роботи мікроконтролера у реальному часі).

### Ковзне середнє (SMA Filter) 
Лінійний фільтр, що обчислює середнє арифметичне значення у заданому вікні `w`.
```python
def update(self, x):
    if len(self.q) == self.w:
        old = self.q[0]
        self.sum -= old
    
    self.q.append(x)
    self.sum += x
    
    return self.sum / len(self.q)
```

### Експоненційне ковзне середнє (EMA Filter)
Рекурсивний фільтр, який згладжує дані з використанням коефіцієнта `alpha` (потребує мінімум пам'яті).
```python
def update(self, x):
    if self.last is None:
        self.last = x
    else:
        self.last = self.a * x + (1 - self.a) * self.last
    
    return self.last
```

### Медіанний фільтр (Median Filter)
Нелінійний фільтр, що повертає медіану поточного масиву значень.
```python
def update(self, x):
    self.q.append(x)
    return np.median(list(self.q))
```

### Аналіз результатів:
*   **Динамічні спотворення (Lag):** Найменше відставання від ідеальної траєкторії демонструє фільтр EMA. SMA має помірну затримку (близько 0.5–1 секунди), тоді як Медіанний фільтр запізнюється найбільше через необхідність накопичення широкого вікна даних.
*   **Реакція на викиди (імпульсний шум):** Медіанний фільтр впорався ідеально — він повністю проігнорував поодинокі апаратні "спайки", пройшовши точно по еталонній траєкторії. Натомість SMA не зміг відкинути ці викиди, а лише "розмазав" їх, зменшивши амплітуду.

### Детальне пояснення парадоксу спектру помилки:
На графіку спектру помилки по осі Y (у діапазоні низьких частот 0 - 1 Гц) спостерігається парадоксальна ситуація: **рівень помилки фільтрів перевищив рівень початкового вхідного шуму**. 

**Чому це сталося?**
При встановленні екстремальних параметрів згладжування фільтри набувають надмірної інерційності. Під час динамічних маневрів (наприклад, руху по синусоїді) алгоритми просто не встигають реагувати на швидкі зміни істинної траєкторії і починають сильно "зрізати кути". Оскільки сам рух об'єкта є низькочастотним процесом, таке спотворення форми генерує величезну систематичну (низькочастотну) похибку, яка амплітудно перевищує високочастотне "тремтіння" сенсора.

## 5. Загальні висновки

Вибір цифрового фільтра напряму залежить від природи перешкод та вимог до динаміки системи:

1.  **Для видалення імпульсних збоїв (викидів сенсора):** Найкращим є **Медіанний фільтр (Median)**. Його суперсила — повне ігнорування аномальних піків. Найвища ефективність досягається при невеликих розмірах вікна (5-11 точок), що дозволяє не втрачати динаміку руху.
2.  **Для плавного ведення траєкторії (придушення білого шуму):** Найкраще підходить **EMA (Експоненційне ковзне середнє)**. Він забезпечує найвищу плавність кривої, найменшу затримку (lag) при маневрах і майже не спотворює форму корисного сигналу.
3.  **Компромісне рішення:** **SMA** гарно пригнічує Гауссів шум, але програє медіані при наявності різких апаратних збоїв. 

Для реальних (production) систем найкращим підходом є каскадна фільтрація: спочатку пропускати "сирий" потік через медіанний фільтр для відсікання "спайків", а потім згладжувати очищений сигнал за допомогою EMA.
